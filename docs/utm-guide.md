# UTMパラメータ命名ルール(よりそいコネクト)

チラシ・動画広告・SNSなど複数の集客施策を横断して比較できるよう、
URLに付与するUTMパラメータの命名ルールを定めます。

**URL生成には社内ツールを使ってください: `/tools/utm-builder/`**
(手入力だと表記ゆれが起きて、GA4上で別施策として集計されてしまいます)

## 基本ルール(全パラメータ共通)

- **すべて半角英数字の小文字**で統一する(`Flyer` ではなく `flyer`)
- スペースは使わない。区切りはアンダースコア `_` を使う
- 日本語は使わない(文字化け・表記ゆれの原因になる)
- 一度使った名前は変更しない(変更するとGA4上で別物として集計される)

## utm_source(施策の出所:どこから来たか)

| 値 | 用途 |
|---|---|
| `flyer` | チラシ・ポスティング |
| `youtube` | YouTube(動画広告・チャンネル投稿とも) |
| `instagram` | Instagram |
| `line` | LINE公式アカウント・LINE配信 |
| `facebook` | Facebook |
| `x` | X(旧Twitter) |
| `google` | Google広告(検索・ディスプレイ) |
| `newspaper` | 新聞折込・地域紙 |
| `poster` | 掲示板・店頭ポスター |
| `referral_partner` | 提携先・紹介元(ケアマネ事業所など) |

新しい販路が増えたら、この表に追記してから使うこと。

## utm_medium(媒体の種類:どんな形式か)

GA4の標準チャネルグループに正しく分類されるよう、以下から選びます。

| 値 | 用途 |
|---|---|
| `print` | 紙媒体(チラシ・新聞・ポスター) |
| `video` | 動画広告 |
| `social` | SNSの通常投稿 |
| `paid_social` | SNSの有料広告 |
| `cpc` | クリック課金型広告(Google広告など) |
| `email` | メール配信 |
| `referral` | 紹介・提携先経由 |
| `qr` | QRコード読み取り(紙以外の設置物など) |

※ 紙のチラシにQRコードを載せる場合は `medium=print` を推奨
(「何の媒体か」を優先。QRはあくまで読み取り手段のため)。

## utm_campaign(施策名:いつ・何の施策か)

**命名規則: `{年}{時期}_{施策内容}_{バージョン}`**

- 年: `2026` のように西暦4桁
- 時期: `spring` / `summer` / `autumn` / `winter`、または `01`〜`12` の月
- 施策内容: `flyer`, `video_ad`, `open_campaign` など内容がわかる英語
- バージョン: 同じ施策でデザイン違い等を比較する場合 `v1`, `v2`, ...

例:

| キャンペーン名 | 意味 |
|---|---|
| `2026summer_flyer_v1` | 2026年夏のチラシ第1弾 |
| `2026summer_flyer_v2` | 同・デザイン違い第2弾(v1と反応比較) |
| `202609_youtube_ad_v1` | 2026年9月のYouTube広告 |
| `2026autumn_carefair` | 2026年秋の介護フェア出展 |

## URL例

```
https://yorisoi-connect.com/moshimoshi-call/?utm_source=flyer&utm_medium=print&utm_campaign=2026summer_flyer_v1
```

## QRコード発行時の注意点

1. **必ずUTMパラメータを付けた完成形のURLからQRコードを作る**こと。
   QRコード化してから「あとでパラメータを足す」ことはできません。
2. **短縮URL(bit.ly等)を使う場合**:
   - 短縮URLは「UTM付きの長いURL」へリダイレクトするだけなので、
     **元のURLにUTMが付いていればパラメータは保持されます**。
   - ただし「短縮URLを作ったあとに元URLのUTMを変えたくなっても変えられない」
     サービスが多いため、短縮前のURL設計を確定させてから短縮すること。
3. **配布前に必ず実機テスト**:
   スマホでQRコードを読み取り → ページが開けること →
   GA4のリアルタイムレポートで utm_source 等が計上されることまで確認する。
4. チラシのデザイン違い(v1/v2)ごとに **QRコードも別々に発行**すると、
   どちらのデザインの反応が良いか比較できます。
5. QRコードは**誤り訂正レベル M 以上**、印刷サイズは **2cm×2cm以上** を推奨
   (高齢のご家族が古い端末で読み取るケースを想定)。

## 運用メモ

- 発行したURL・QRコードは、施策名・配布日・配布枚数とセットで
  一覧表(スプレッドシート等)に記録しておくと、あとで効果比較がしやすくなります。
- GA4での確認場所: 「レポート → 集客 → トラフィック獲得」で
  セッションのソース/メディア/キャンペーン別に閲覧できます。
