# Googleフォーム:回答後にサンクスページへ誘導する設定手順

お問い合わせフォーム(もしもしコール)の送信完了を GA4 で計測するため、
回答完了後にサンクスページ
`https://yorisoi-connect.com/moshimoshi-call/contact/thanks/`
へ誘導する設定を行います。

## 前提と重要な注意点

**Googleフォームには「送信後に自動でリダイレクトする」機能はありません。**
できるのは「送信完了画面(確認メッセージ)にリンクを表示し、回答者にタップしてもらう」ことまでです。
そのため、確認メッセージの文言で自然にタップを促す書き方にします。

- サンクスページに到達した人だけが `generate_lead` としてカウントされます。
  リンクをタップしなかった人は計測されません(実際の送信数より少なめに出ます)。
- より正確に全送信を計測したい場合は、将来的にGoogleフォームをやめて
  自前フォーム(FormspreeやGAS等)に切り替える選択肢があります。

## 設定手順

1. Googleフォームの編集画面を開く
   - 対象フォーム: もしもしコール お問い合わせフォーム
     (フォームID: `1FAIpQLSdBZ9C9dZWfS5t3mgpykSNlS0Q3jS8nZ1QsNicTkHHuTrhzRA` の編集元フォーム)
   - フォームの管理者アカウントでログインして開きます。

2. 画面上部の **「設定」** タブをクリック

3. **「表示設定」(プレゼンテーション)** セクションを展開

4. **「確認メッセージ」** の「編集」をクリックし、以下のように入力する

   ```
   お問い合わせありがとうございました。
   下記リンクをタップして、受付完了ページをご確認ください。

   https://yorisoi-connect.com/moshimoshi-call/contact/thanks/
   ```

   ※ URLをそのまま貼ると自動でリンクとして表示されます。

5. 「保存」をクリック

## 動作確認手順

1. シークレットウィンドウで
   `https://yorisoi-connect.com/moshimoshi-call/contact/` を開く
2. 埋め込みフォームからテスト送信する(氏名欄に「テスト」等と入力)
3. 送信完了画面に確認メッセージとサンクスページへのリンクが表示されることを確認
4. リンクをタップし、サンクスページが表示されることを確認
5. GA4 の「レポート → リアルタイム」で `generate_lead` イベントが
   計上されていることを確認
6. テスト回答は、フォームの「回答」タブ →(必要なら)スプレッドシートから削除する

## 補足

- 確認メッセージ内のリンクは埋め込みiframeの中でもタップ可能で、
  新しいタブでサンクスページが開きます(親ページのデザインには影響しません)。
- サンクスページは `noindex` 設定済みのため、検索結果には表示されません。
