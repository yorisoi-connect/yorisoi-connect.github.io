# GA4・Search Console 手作業タスクのチェックリスト

コード変更では対応できず、各管理画面での手作業が必要な項目の一覧です。
上から順に対応してください。

## 1. キーイベントの登録(GA4)

`generate_lead` / `click_tel` / `view_section` を「キーイベント」として登録し、
成果(コンバージョン)として集計されるようにします。

- [ ] GA4(https://analytics.google.com)を開き、対象プロパティを選択
- [ ] 左下の **管理(歯車)→ データの表示 → キーイベント** を開く
- [ ] 「**新しいキーイベント**」をクリックし、イベント名に `generate_lead` と入力して保存
- [ ] 同様に `click_tel` を登録
- [ ] `view_section` は登録**しない**ことを推奨
  (ページを見れば頻繁に発火するため、キーイベントにすると成果指標が薄まります。
   興味関心の分析用として通常イベントのまま見るのがおすすめです。
   それでも成果として扱いたい場合のみ同様に登録してください)

※イベント名は大文字小文字も含めて正確に入力すること。
※実際にイベントが1回でも計測されると「管理 → イベント」の一覧に表示され、
  一覧のスイッチからもキーイベント化できます。

## 2. カスタムディメンションの登録(GA4)※レポートで内訳を見るために必要

独自パラメータ(section_name 等)は、登録しないとレポートの分析軸に使えません。

- [ ] **管理 → データの表示 → カスタム定義 → カスタムディメンションを作成** を開く
- [ ] 以下を1件ずつ登録する(範囲はすべて「イベント」)

| ディメンション名 | イベントパラメータ |
|---|---|
| セクション名 | `section_name` |
| 電話番号 | `phone_number` |
| リード獲得元 | `lead_source` |

※ `page_path` は標準の「ページパスとスクリーンクラス」で代替できるため登録不要です。
※登録以降のデータから集計されます(過去分には遡及されません)。早めの登録を推奨。

## 3. 内部トラフィック(自分のアクセス)の除外設定(GA4)

- [ ] **管理 → データ収集と修正 → データストリーム** → 対象のウェブストリームを開く
- [ ] **タグ設定を行う →(すべて表示)→ 内部トラフィックの定義** を開く
- [ ] 「作成」をクリックし、以下を設定して保存
  - ルール名: 例「自宅・作業場所」
  - traffic_type の値: `internal`(既定のまま)
  - IPアドレス: 「IPアドレスが次と等しい」+ 自分のグローバルIP
    (「IPアドレスを確認」等で調べる。固定でない場合は範囲指定 or 都度更新)
- [ ] **管理 → データ収集と修正 → データフィルタ** を開く
- [ ] 「Internal Traffic」フィルタが**「テスト」**状態で作成されているので、
      動作確認後に**「有効」**に切り替える
  - テスト状態のうちは除外されず、「テストデータのフィルタ名」ディメンションで
    確認だけできます。リアルタイムレポートで自分のアクセスに
    フィルタ名が付くことを確認してから有効化してください。

**注意**: スマホ回線(4G/5G)はIPが変わるため、この方法では除外できません。
スマホから確認するときは、確認専用と割り切るか、計測結果を読む際に
自分のアクセス分を念頭に置いてください。

## 4. Bot除外設定の確認(GA4)

- [ ] 対応不要であることの確認のみ:GA4では**既知のボット・スパイダーの
      トラフィックは自動的に除外**されており、無効化もできない仕様です
      (UA(旧アナリティクス)にあった「ボットのフィルタリング」チェックボックスは
      GA4には存在しません)。
- [ ] 心配な場合は「レポート → リアルタイム」で不自然な大量アクセスがないかを
      ときどき確認する程度でOKです。

## 5. Google Search Console との連携

- [ ] サイト所有権の確認: **docs/search-console-setup.md** の手順で実施
- [ ] 所有権確認後、サイトマップ(`sitemap.xml`)を送信
- [ ] GA4との連携:
  - GA4の **管理 → サービス間のリンク設定 → Search Console のリンク** を開く
  - 「リンク」→ Search Console プロパティ(`https://yorisoi-connect.com/`)を選択
  - ウェブストリームを選択して送信
- [ ] GA4のレポートに検索クエリを表示する:
  - **レポート → ライブラリ**(左メニュー最下部)を開く
  - 「Search Console」コレクションを**公開**する
  - 以降「レポート → Search Console → クエリ」で検索ワードが見られます

## 6. Googleフォームの回答後リンク設定

- [ ] **docs/google-form-redirect-guide.md** の手順で、確認メッセージに
      サンクスページURL(`https://yorisoi-connect.com/moshimoshi-call/contact/thanks/`)を設定
- [ ] テスト送信 → サンクスページ表示 → GA4リアルタイムで `generate_lead` を確認

## 7. 設定完了後の全体動作確認

- [ ] スマホ実機でサイトを開き、GA4「リアルタイム」レポートに自分が表示されること
- [ ] 電話リンクをタップ → `click_tel` がリアルタイムに計上されること
- [ ] 料金セクションまでスクロール → `view_section` が計上されること
- [ ] 内部トラフィックフィルタ有効化後、自分のアクセスが計上**されない**こと
